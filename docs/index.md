# Documentation Index

Welcome to the documentation for the **Printable Sports TV Listings** project.  
This folder contains detailed guides explaining how the code works, how to configure it, and how the two main scripts (weekly and single-day) differ.

---

## Overview

The project generates **print-ready Excel sheets** showing televised sports schedules for a custom cable channel lineup.

- **Weekly Listings**: Multi-day grid (e.g. Monday–Friday or full week)
- **Single-Day Listings**: Focused, high-density layout for one day (ideal for busy Saturdays)

Both versions share the same ESPN-based data pipeline and Excel rendering system.
